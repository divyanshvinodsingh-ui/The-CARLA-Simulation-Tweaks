# Autonomous Vehicle Simulation & Controller Tweaks

An exploration into autonomous driving physics using the open-source CARLA Simulator, focusing on tweaking Python physics logic scripts for vehicle velocity, throttle, and automated steering parameters.

### 📈 Project Roadmap & Backlog
* **Origin:** Developed during middle school (6th/7th grade) as an introductory project into autonomous vehicle kinematics.
* **Current Status:** Retained as a foundational simulation portfolio piece.
* **Next Steps:** Planning a 3–4 month revision timeline to re-familiarize with the CARLA API environment, optimize logic scripts, and fix legacy simulation dependencies.
